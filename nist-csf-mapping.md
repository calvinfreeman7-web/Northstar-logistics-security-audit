
# NIST Cybersecurity Framework Mapping

## Purpose

This section maps NorthStar Logistics' cybersecurity activities and recommended controls to the six functions of the NIST Cybersecurity Framework (CSF) 2.0.

## NIST CSF Mapping

| Function | Security Activity | NorthStar Application |
|---|---|---|
| Govern | Establish cybersecurity policies and assign risk-management responsibilities | Define security policies, responsibilities, and organizational risk-management practices |
| Identify | Maintain an asset inventory and assess cybersecurity risks | Identify critical systems, data, vulnerabilities, and business risks |
| Protect | Implement MFA and role-based access controls | Reduce unauthorized access to company accounts, systems, and sensitive information |
| Detect | Monitor endpoints and network activity using EDR | Identify suspicious behavior, malware, and potential security incidents |
| Respond | Contain compromised devices and execute incident response procedures | Limit the impact of security incidents and coordinate response activities |
| Recover | Restore affected systems and data from verified backups | Restore business operations and critical information following an incident |

## Summary

Mapping the recommended controls to the NIST Cybersecurity Framework provides NorthStar Logistics with a structured approach to managing cybersecurity risk.

The assessment addresses preventive, detective, response, and recovery capabilities while also establishing governance and risk-management practices.
