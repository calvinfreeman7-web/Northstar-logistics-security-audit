# Northstar-logistics-security-audit
Cybersecurity risk assessment and security audit for a simulated logistics organization using the NIST Cybersecurity Framework.
## Project Overview

NorthStar Logistics is a simulated transportation and logistics company used for this cybersecurity risk assessment.

The purpose of this project is to identify cybersecurity risks, evaluate existing security controls, and recommend improvements using the NIST Cybersecurity Framework (NIST CSF).

## Objectives

- Identify critical organizational assets
- Identify cybersecurity threats and vulnerabilities
- Assess and prioritize security risks
- Evaluate existing security controls
- Recommend appropriate security improvements
- Map findings to the NIST Cybersecurity Framework

## Organization Environment

NorthStar Logistics has approximately 50 employees and uses:

- Employee laptops
- Company email accounts
- Cloud file storage
- Office Wi-Fi
- Transportation Management System (TMS)
- Customer database
- Employee smartphones
- Backup systems

## Security Concerns

The organization has recently experienced suspicious phishing emails. Management requested a cybersecurity assessment to determine potential vulnerabilities and reduce the organization's overall cyber risk.

## Framework

This assessment uses the NIST Cybersecurity Framework (CSF) to organize cybersecurity activities around:

- Govern
- Identify
- Protect
- Detect
- Respond
- Recover

## Project Deliverables

- Asset Inventory
- Risk Register
- Security Controls Assessment
- NIST CSF Mapping
- Executive Summary
