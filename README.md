# NorthStar Logistics Cybersecurity Risk Assessment

## Project Overview

This project is a simulated cybersecurity risk assessment and security audit for NorthStar Logistics, a transportation and logistics organization with approximately 50 employees.

The objective was to identify critical assets, assess cybersecurity risks, recommend appropriate security controls, and map those controls to the NIST Cybersecurity Framework (CSF) 2.0.

## Scenario

NorthStar Logistics relies on employee laptops, cloud services, company email, office Wi-Fi, a Transportation Management System (TMS), customer data, and backup systems.

Following suspicious phishing activity, a cybersecurity assessment was conducted to evaluate the organization's security posture and identify areas requiring remediation.

## Methodology

The assessment included:

1. Asset identification and classification
2. Threat and vulnerability identification
3. 5x5 cybersecurity risk scoring
4. Security control recommendations
5. Risk-based remediation prioritization
6. NIST CSF 2.0 mapping
7. Executive-level reporting

## Key Findings

Five primary cybersecurity risks were identified:

| Risk | Score | Rating |
|---|---:|---|
| Ransomware | 25 | Critical |
| Phishing / Credential Theft | 16 | High |
| Unauthorized Access / Excessive Permissions | 12 | High |
| Data Loss / Backup Failure | 8 | Medium |
| Insecure Wi-Fi / Network Access | 6 | Medium |

Ransomware was identified as the highest-priority risk, followed by phishing/credential theft and excessive access permissions.

## Recommended Security Controls

- Endpoint Detection and Response (EDR)
- Multi-Factor Authentication (MFA)
- Role-Based Access Control (RBAC)
- Regular user access reviews
- Automated backups and restoration testing
- WPA3 wireless encryption
- Network segmentation

## NIST CSF 2.0 Alignment

Security activities were mapped to all six NIST CSF 2.0 functions:

- Govern
- Identify
- Protect
- Detect
- Respond
- Recover
