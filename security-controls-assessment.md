# Security Controls Assessment

## Purpose

This assessment identifies security controls that NorthStar Logistics can implement to reduce the cybersecurity risks identified in the risk register.

Controls are prioritized based on the severity of the identified risks and their potential impact on business operations.

## Control Assessment

| Risk | Recommended Control | Priority |
|---|---|---|
| Phishing / Credential Theft | Require multi-factor authentication (MFA) for all company accounts | High |
| Ransomware | Deploy endpoint detection and response (EDR) and centrally managed anti-malware | Critical |
| Unauthorized Access / Excessive Permissions | Implement role-based access control (RBAC) and conduct regular access reviews | High |
| Insecure Wi-Fi / Network Access | Implement WPA3 encryption, strong authentication, and separate guest Wi-Fi from the corporate network | Medium |
| Data Loss / Backup Failure | Implement automated backups with scheduled restoration testing | Medium |

## Control Summary

The highest-priority security controls focus on reducing the organization's exposure to ransomware, phishing, credential theft, and unauthorized access.

Multi-factor authentication helps protect company accounts from compromised credentials, while endpoint detection and response provides additional protection against ransomware and malicious activity.

Role-based access control and regular access reviews help enforce the principle of least privilege. Network security improvements reduce unauthorized access to internal resources.

Automated backups and scheduled restoration testing help ensure that NorthStar Logistics can recover critical business data following ransomware, system failure, or data corruption.
